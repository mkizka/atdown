# @mkizka/create-atdown

atdownプロジェクトのスキャフォールドツール。

## 使い方

```bash
npx @mkizka/create-atdown
# or
yarn create @mkizka/atdown
# or
pnpm create @mkizka/atdown
```

対話形式で以下を設定します:

- ハンドル
- エントリーディレクトリ
- 使用するコンバーター

## 生成されるファイル

- `atdown.json`: 設定ファイル
- `.env`: 環境変数テンプレート
- `entries/`: エントリーディレクトリ
